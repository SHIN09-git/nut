# v1 物种与养护参数审校计划

状态：R1 研究规格

当前 `Species_A`、生命周期、湿度和行为数值全部是 `prototype_pacing_fixture`，只服务节奏验证，不能描述成真实物种数据或现实养护建议。

## 审校目标

在正式内容和发行文案冻结前完成：

1. 选择一个首发物种或明确采用虚构综合物种。
2. 区分科学事实、常见养护实践、游戏抽象和纯节奏参数。
3. 审校生命周期相对顺序、护理行为、食性、湿度／遮光／污染反应和群落规模表达。
4. 删除现实中危险、误导或无法支持的剂量与温度建议。
5. 保留“3～4 小时是教学压缩，不代表真实生长速度”的明确说明。

## 来源优先级

| 等级 | 来源 | 用途 |
| --- | --- | --- |
| A | 同行评议论文、博物馆／大学资料 | 行为与生物学事实 |
| B | 兽医、专业蚁学组织、具名养护专家 | 安全养护边界与实践 |
| C | 有长期记录的养蚁者文章／视频 | 观察顺序、常见设备与可读性线索 |
| D | 商家页面、论坛、社交媒体 | 仅作候选线索，不能单独支持参数 |

任何商业资料都不能构成图片、视频、音频、字幕或产品外观的使用许可。

## 待审校问题

### 物种身份

- 首发物种是否适合单后试管到小型模块巢的教学路径。
- 是否存在明显多后、特殊蛹型、特殊营养或危险防护要求。
- 工蚁与蚁后体型和颜色能否在当前镜头下清晰区分。

### 生命周期

- 卵、幼虫、蛹、首工出现的真实相对尺度和变异范围。
- 是否结茧；若存在裸蛹／茧蛹差异，当前程序化轮廓应如何调整。
- 蚁后与首工的护理分工是否符合所选物种。

### 营养

- 糖类／蛋白抽象适用范围。
- 幼体蛋白供给和成虫糖类摄取的表述边界。
- 禁止把游戏“份数”映射为现实剂量。

### 环境

- 湿度偏好是否适合用区域比较表达。
- 遮光、干扰和污染线索是否合理。
- 温区是否有独立、可信且安全的因果闭环；没有则延期。

### 行为

- 幼体搬运、废物集中、侦察、迁巢和营养交换的可支持事实。
- 哪些行为只是确定性游戏抽象，必须在手册中标记。

## 专家审阅流程

1. 开发团队先形成问题清单和来源摘要，不要求专家替项目做开放式研究。
2. 至少一名具名、可核验背景的蚁类养护专家审阅安全和养护表达。
3. 对关键生物事实优先取得第二来源；存在分歧时保留条件和不确定性。
4. 将决定映射回强类型 Resource 字段与玩家文案。
5. 修改配置后重跑确定性、章节节奏和存档迁移测试。

## 停止条件

- 无法为物种关键行为找到可靠支持。
- 现实安全边界与游戏操作冲突。
- 温区只能复制湿度玩法或需要显示现实剂量。
- 正式素材依赖无法确认物种或授权的照片。

满足停止条件时，优先保持虚构综合物种与明确原型标签，不伪装成真实物种。
