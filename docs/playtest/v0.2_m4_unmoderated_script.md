## 给测试者的文字

请将以下内容原样提供给每名参与者，不作补充解释：

> 这是一个仍在开发中的短体验。请从提供的压缩包解压并启动程序，只根据游戏画面中能看到的信息观察和操作。
>
> 请尝试进行体验，直到你认为这次连续观察已经完成。你可以按自己的判断使用画面中的控件；如果不确定下一步，也请直接说出你正在想什么。
>
> 体验过程中请一边操作，一边说出你正在注意什么、你认为发生了什么，以及你为什么决定进行某项操作。请不要查阅项目说明、其他文件或向记录员询问答案。
>
> 到达你认为的完成状态后，请先告诉记录员“我认为完成了”，再尝试开始一轮新的观察，确认能够重新开始，然后正常退出程序。

参与者完成或停止后，记录员依次原样提问：

1. “这局里环境变化后，工蚁和幼体发生了什么？你认为为什么？”
2. “糖水出现后，你观察到什么？它最后去了哪里？”
3. “你是否特别关注某只工蚁？为什么？你给它命名了吗？你记得它做过什么？”
4. “哪个时刻你最不清楚下一步？当时发生了什么，大约持续多久？”
5. “你怎样判断这次体验已经完成？重新开始和退出是否符合预期？”

只允许在没有听清时请参与者重复原话。不得改成选择题，不得提示关键词，不得用追问补齐参与者未主动表达的因果或行为。

## 记录员测试前准备

第一名测试者开始前完成以下事项，并在整轮中保持不变：

1. 预先登记 P01～P07 的匿名编号和测试顺序。若出现无效样本，保留该编号及记录，再追加 P08、P09 等替补，不得删除或事后挑样本。
2. 确认参与者第一次接触本项目、未参与开发、未阅读设计或测试文档、未看过其他人的试玩。
3. 在参与者接触文件前校验分发包 SHA-256；解压后校验 EXE 与 PCK SHA-256。
4. 每人使用全新解压目录并从未运行状态开始。记录 Windows 版本、显示分辨率和非识别性的硬件概况。
5. 准备独立计时与逐字记录。若录屏，先取得参与者同意；原始视频和个人身份信息不得提交仓库。
6. 不向参与者提及开发诊断键、内部阶段、正确答案、推荐速度、操作次数或预期完成时间。

## 有效样本

计入 Gate 的样本必须同时满足：

- 参与者未参与开发，且是第一次接触本项目和该构建。
- 使用上方三个哈希完全匹配的冻结候选。
- 测试前未接触玩法答案、评分规则、设计文档或他人结果。
- 全程没有场外玩法提示，也没有出现开发诊断层。
- 保留完整计时、关键行为、所有介入和五个体验后问题的逐字回答。

若存在先验知识、任何玩法提示、诊断层污染、错误构建、评分规则泄露或关键原始记录缺失，该样本标记为无效。无效记录必须保留并说明原因，但不计入分母；追加新的合格参与者，直到取得 7 名有效样本。

## 记录员行为边界

正式计时后，记录员只记录，不解释、不确认“做对了”、不建议操作。

下列行为属于禁止提示：

- 指出应关注哪个巢室、工蚁、幼体、按钮或画面变化。
- 解释补水、湿度、搬运、觅食、返巢、分享或观察卡的含义。
- 告诉参与者应点击几次、何时等待、何时切换速度或应选择哪只工蚁。
- 要求或建议参与者选择、命名、追踪某只工蚁。
- 告知当前处于哪个内部阶段，或距离完成还有多久。

仅可协助排除游戏外部的启动障碍，例如操作系统安全提示或损坏的解压目录。每次介入必须逐字记录内容和时间；若介入涉及游戏目标、控件或答案，该样本立即无效。

所有体验后回答和评分证据锁定前，不得向参与者解释正确答案。

## 统一计时口径

每名参与者记录以下墙钟时间点，使用相对于 T0 的 `mm:ss`：

- **T0**：程序首次显示可操作的准备门，开始按钮已经可用。
- **T1**：参与者点击开始观察。
- **T2**：身份观察阶段首次可见。
- **T3**：湿度观察阶段首次可见。
- **T4**：糖水观察阶段首次可见。
- **Tsummary**：三条观察线索完成的总结画面首次可见。
- **Tconfirm**：参与者主动表示自己认为体验已经完成。
- **Trestart**：重新开始后准备门再次可见。
- **Texit**：程序窗口正常退出。

同时记录：

- 门前阅读时间：`T1 - T0`
- 门后体验时间：`Tconfirm - T1`
- 有效首通总时长：`Tconfirm - T0 - 明确排除时段`

只有以下时段可以排除，并必须记录起止、原因和时长：

- T0 前的解压、哈希校验、录制设置等测试准备。
- 因非游戏原因导致应用连续失焦至少 30 秒的外部中断。
- 记录员处理启动或硬件故障、且没有提供任何游戏信息的恢复时段。

阅读界面、思考、尝试控件、主动观察正在发生的行为、等待自己已经识别的反馈，都属于有效体验时间，不得排除。不能通过无信息闲置填充目标时长。

若参与者明确放弃、出现阻塞故障或从 T0 起 25 分钟仍未完成，结束首通并记录为未完成；仍需进行体验后提问。

## 冻结评分口径

本节在第一名测试者开始前冻结，整轮不得事后改写。

### 无讲解完成

参与者在没有玩法提示的情况下：

1. 自行到达三条观察线索完成的总结画面；
2. 主动表示自己认为体验已经完成。

只到达总结但需要记录员告诉其“已经结束”，或未到达总结，不计为完成。

### 正确描述湿度因果

回答必须同时明确表达：

- 玩家补水或改变了巢室的潮湿／环境条件；以及
- 工蚁因此重新安排、搬运或改变幼体位置，使幼体趋向更合适的巢室或条件。

只说“工蚁搬了幼体”“按按钮后画面变了”或仅复述最终位置，不通过。

### 正确描述糖液往返与分享

回答必须同时明确表达：

- 工蚁发现或采集糖水，并将其携带／带回巢内；以及
- 糖水随后被巢内个体分享、传递或供群落使用。

只说“工蚁吃了糖”“糖水消失了”或只描述单程移动，不通过。

### 主动选择工蚁

参与者在体验后提问之前、没有收到选择指令时，有意点击并查看某只工蚁。误点、只点击空白区域、或记录员提出问题后才选择，不计入。

### 主动命名且能回忆行为

参与者在没有命名提示时，自行选择工蚁、输入并保存非空名称；体验后又能回忆该个体至少一个在本局观察到的具体行为或事件。只有命名或只有泛泛描述，不通过。

### 因不知道下一步而卡住

参与者连续至少 120 秒明确表示不知道下一步，或反复寻找下一步但无法形成有效判断。主动阅读、思考、观察正在发生的搬运或觅食反馈，不自动算作卡住。

### 阻塞稳定性问题

以下任一项视为阻塞问题：

- 候选无法启动或在正常路径崩溃。
- 输入长期无响应且参与者无法自行恢复。
- 完成后无法重新开始。
- 无法通过正常窗口操作退出。

## Gate

只统计 7 名有效样本，所有条件必须同时满足：

- 至少 5/7 无讲解完成。
- 至少 4/7 正确描述湿度因果。
- 至少 4/7 正确描述糖液往返与分享。
- 至少 3/7 主动选择工蚁。
- 至少 2/7 主动命名且能回忆行为。
- 没有人因不知道下一步卡住超过 2 分钟。
- 没有阻塞崩溃、无法启动、无法重开或无法退出。
- 完成者的有效首通总时长中位数为 12～15 分钟；保留并报告全部实际时长。

在 7 名有效样本及逐人原始记录尚未完成前，R0-B 只能标记为 `INCOMPLETE`，不得声称 Gate 通过。
