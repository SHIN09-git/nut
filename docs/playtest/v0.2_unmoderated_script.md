## 测试前准备

1. 预登记 P01～P07；无效样本保留并追加替补，不事后挑样本。
2. 参与者必须未参与开发、第一次接触本项目和该候选。
3. 在参与者接触文件前校验 ZIP；解压后校验 EXE 与 PCK。
4. 每人使用全新解压目录，记录 Windows 版本、显示分辨率和缩放。
5. 记录完整计时、关键操作、所有介入和体验后逐字回答。
6. 不提 F3、内部阶段、正确操作次数、推荐速度或预期时长。
7. 若录屏，先取得同意；身份信息与原始视频不提交仓库。

## 有效样本

- 测试前未看到玩法答案、评分规则或他人结果。

## 计时点

使用相对 T0 的 `mm:ss`：

- T0：准备门首次可操作。
- T1：点击开始观察。
- T2：身份观察阶段首次可见。
- T3：湿度观察阶段首次可见。
- T4：糖水阶段首次可见。
- Tsummary：总结首次可见。
- Tconfirm：参与者主动确认完成。
- Trestart：重开后的准备门可见。
- Tmenu：重开后暂停菜单可见。
- Texit：窗口正常退出。

记录门前阅读、门后体验、有效首通总时长和所有外部中断。阅读、思考和观察行为反馈属于体验时间，不能排除。

## 冻结判定

- **无讲解完成**：自行到达三张观察卡完成的总结，并主动确认完成。
- **湿度因果**：同时表达玩家改变巢室环境，以及工蚁因此重新安排幼体位置。
- **糖水往返与分享**：同时表达工蚁采集／携带糖水回巢，以及随后发生巢内分享或传递。
- **主动选择**：体验后提问前、没有收到指令时有意选择工蚁。
- **主动命名并回忆**：自行命名，且结束后能回忆该个体至少一个具体行为。
- **卡住**：连续至少 120 秒明确不知道下一步或反复寻找而无法形成有效判断。
- **阻塞问题**：无法启动、崩溃、输入不可恢复、无法重开或无法正常退出。
