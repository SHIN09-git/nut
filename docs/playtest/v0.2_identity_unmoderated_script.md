# v0.2 M2 工蚁身份无讲解试玩脚本

本脚本用于验证玩家是否会在没有开发者提示的情况下，把某一只工蚁当作持续存在的个体。不要提前解释选择、命名或行动记录功能。

## 样本与环境

- 至少 5 名未参与项目开发、第一次接触本候选版本的测试者。
- 全部测试使用同一提交和同一 Windows 构建。
- 每次从全新启动开始，F3 诊断层保持关闭。
- 每名测试者单独体验；建议预留 10 分钟。
- 记录屏幕、操作和原话；不得根据回忆补写。

## 给测试者的唯一说明

> 这是一个仍在开发中的短体验。请只根据画面中能看到的信息自由观察和操作，直到你认为体验已经完成。请一边体验一边说出你正在注意什么，以及为什么进行某项操作。

说明后开始计时。记录员不得指出工蚁、身份面板、命名框、选中轮廓或行动记录，也不得建议测试者执行任何特定操作。

## 记录事项

只记录可观察事实：

- 测试者是否主动点击某一只工蚁，以及首次点击时间。
- 测试者是否主动输入并保存名称，以及首次命名时间。
- 测试者是否在之后再次辨认或提到同一只工蚁。
- 测试者如何描述选中轮廓、当前行为和最近行动。
- 测试者是否误以为能够直接命令该工蚁。
- 身份面板、补水闭环、重开或退出是否出现阻塞问题。

若记录员提示了选择或命名，该测试者保留记录但不计入 M2 Manual Gate，并补充新的有效样本。

## 体验后提问

退出程序后按顺序提问，不提供答案关键词：

1. “体验中有没有一个具体角色让你特别注意？为什么？”
2. “如果有，它做过哪些事情？”
3. “你觉得你能控制它吗？你实际改变了什么？”
4. “画面中哪些信息帮助你确认那是同一个角色？”
5. “重新开始后，你预期刚才留下的信息会怎样？”

逐字记录回答。只有测试者在体验中确实选择过工蚁时，才判定其能否描述“所选工蚁”的具体行动。

## Gate

至少 5 个有效样本中必须同时满足：

- 至少 3/5 主动选择一只工蚁。
- 至少 2/5 主动为它命名。
- 至少 2/5 在结束后能描述所选工蚁至少做过一件事。

自动测试、开发者自测和 Agent 检查不能替代该 Gate。
