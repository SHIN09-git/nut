## 样本有效性

计入 Gate 的每名测试者必须同时满足：

- [ ] 非项目开发者。
- [ ] 第一次接触本版本。
- [ ] 测试前未阅读玩法说明、设计文档或其他测试结果。
- [ ] 使用相同候选构建并从全新启动开始。
- [ ] 全程没有打开开发者诊断信息。
- [ ] 未收到关于目标、环境含义、正确操作、操作次数或行为顺序的提示。

若任一项不满足，将该名标记为“无效样本”，保留记录但不计入分母；补充新的有效测试者，直到有效样本不少于 5 人。

## 统一判定口径

- **无讲解完成闭环**：测试者自行启动，只凭普通界面操作，看到明确完成状态并自行判断已完成；记录员未提供玩法提示。
- **正确表达因果**：测试者自己的原话明确连接“环境被玩家改变”与“工蚁随后改变幼体位置”。同义表述可以通过；只说“按按钮就播动画”“蚂蚁在动”或由记录员提示后复述，不通过。
- **注意到携带关系**：测试者在未使用诊断层的情况下，主动说出或在体验后无提示回忆出工蚁携带、叼起或带着幼体移动。仅注意到幼体最终换了位置，不通过。
- **因为不知道下一步而卡住**：测试者明确表示不知道下一步，或持续尝试寻找下一步但没有形成有效判断。主动观察正在发生的行为、阅读界面或等待已识别的反馈，不自动算作卡住。
- **阻塞问题**：崩溃、卡死、输入长期无响应，或完成后无法开始新一轮，且测试者不能自行恢复。

Gate 判定只使用逐人计时、录像和原话。临界或证据不足的项目按“不通过”处理，并在备注中说明。
