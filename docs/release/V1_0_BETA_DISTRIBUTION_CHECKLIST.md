# v1.0 Beta candidate distribution checklist

This checklist prepares a portable Windows x86_64 candidate. It does not
authorize a `main` merge, tag, GitHub Release, store upload, or public
distribution.

## Source gate

- [ ] Current branch is `release/v1.0-beta`.
- [ ] Worktree contains no generated editor data, local executable, secret,
      log, save, build, or internal `sucai/` content.
- [ ] Godot reports exactly `4.7.1.stable`.
- [ ] Matching official Windows export templates are installed.
- [ ] Headless editor parse passes.
- [ ] Standard test runner passes with the final assertion count.
- [ ] Default headless main-scene smoke passes.
- [ ] Existing 144,000 Tick complete-profile soak passes.
- [ ] 300,000 Tick maximum-scale soak passes with finite values, legal
      ownership, entity counts, memory trend, save size, and snapshot signature.
- [ ] Maximum-scale rendered frame sample is recorded.
- [ ] Save migration fixtures through `r12.authority.v10` pass.

## Rights and package content

- [ ] Every production asset is `approved_production` in
      `docs/production/asset_ledger.csv`.
- [ ] `sucai/`, tests, tools, docs, debug scenes, and obsolete standalone
      scenes are absent from the PCK.
- [ ] `CREDITS.md`, `PRIVACY.md`, and `RELEASE_NOTES_V1_0_BETA.md` are current.
- [ ] `docs/production/GODOT_COPYRIGHT.txt` was regenerated with the exact
      release engine.
- [ ] The package contains renamed reader copies:
      `CREDITS.txt`, `PRIVACY.txt`, `RELEASE_NOTES.txt`, and
      `THIRD_PARTY_NOTICES.txt`.
- [ ] The in-game Credits & Privacy page opens in both languages.

## Build

1. Export the `Windows Desktop` release preset to:

   ```text
   builds/windows/ColonyUnderGlass_v1.0_beta.exe
   ```

2. Keep the adjacent PCK generated by the non-embedded preset.
3. Copy the four reader documents listed above into the same distribution
   directory.
4. Record SHA-256 for every shipped file and for the final archive.
5. Freeze the exact commit SHA in the validation record before creating the
   final archive.

The candidate is unsigned. Signing is not implied and must not be reported as
complete.

## Isolated Windows path

Use empty temporary `APPDATA` and `LOCALAPPDATA` roots so normal user data is
never touched.

- [ ] Copy the package into an empty temporary application directory.
- [ ] First launch reaches the title page without editor or console files.
- [ ] New Game reaches the Tick 0 preparation gate.
- [ ] Start, advance, pause, save, return to title, and Continue restore the
      exact saved Tick and paused state.
- [ ] A completed `r12.authority.v10` profile loads and exposes the report and
      both finale choices.
- [ ] Backup recovery and confirmed profile deletion still work.
- [ ] Exit closes the process cleanly.
- [ ] Removing the temporary application directory removes the portable
      application while isolated local data remains understandable per
      `PRIVACY.txt`.
- [ ] Removing the isolated data root completes the clean uninstall test.

## Display matrix

- [ ] 1280×720 windowed at 100% and 150%.
- [ ] 1920×1080 windowed at 100% and 150%.
- [ ] Fullscreen at 100% and 150%.
- [ ] Simplified Chinese and English.
- [ ] Normal and reduced motion.
- [ ] Title, Credits & Privacy, settings, profile, preparation gate, main
      observation, layout, journal, pause, and finale report.
- [ ] F3 has no effect in the release build.
- [ ] Carrying, facility states, focus, placement validity, and environmental
      clues remain readable without debug text.

## Release decision

- [ ] No open P0 or P1 defect.
- [ ] Technical candidate evidence is complete.
- [ ] External full-profile Gate is explicitly `INCOMPLETE` until valid data
      exists.
- [ ] Separate user authorization has been received for each requested action:
      merge `main`, create `v1.0.0` tag, create GitHub Release, or publish to a
      store.
