# v1 资产与许可计划

状态：R14 首批生产资产已登记；R15 音频与 R16 发行复核待完成

## 原则

- 正式发行资产必须原创、委托且权利明确，或来自允许商业发行与宣传的许可证。
- `sucai/` 只作内部参考，来源和授权未确认前不得进入构建、仓库发行内容、宣传图或商店页面。
- 参考游戏、商家产品和养蚁视频只能用于事实与一般交互研究，不复制界面、图标、产品造型、旁白、镜头编排、音乐或文本。
- 任何外部资产在进入 `assets/production/` 前必须有台账记录。

## 台账字段

每个资产使用稳定 `asset_id`，在 `docs/production/asset_ledger.csv` 记录：

```text
asset_id
category
repository_path
source_type
creator
source_url_or_contract
license_name
commercial_game_use
marketing_use
modification_allowed
redistribution_allowed
attribution_text
species_review_status
approval_status
approved_by
approved_date
notes
```

`approval_status` 只能为：

- `reference_only`
- `pending_rights`
- `approved_production`
- `rejected`

只有 `approved_production` 可以进入发行导出。

## 生产流程

1. 用程序化灰盒锁定尺寸、命中、镜头和状态。
2. 为每项资产写原创 brief，列出功能需求与禁止复制的参考特征。
3. 取得源文件、合同／许可证和作者身份。
4. 更新台账并由项目负责人批准。
5. 进入仓库后检查来源、命名、尺寸、导入设置和许可文件。
6. 在 1280×720、1920×1080、100%／150% UI 缩放和减少动效下验收。
7. R16 导出前生成 Credits 与许可清单，检查包内没有 `reference_only` 或 `pending_rights`。

## 委托最低权利

- 永久、全球、商业游戏使用。
- Windows 发行、补丁和宣传使用。
- 为适配、裁切、压缩、颜色和动画进行修改。
- 在游戏构建中再分发最终资产。
- 明确署名要求和源文件交付范围。
- 明确是否允许作者将作品集公开以及保密期。

## 禁止提交

- 未知来源的图片、字体、音效或音乐。
- 从视频、商店页、社交媒体或搜索结果直接保存的发行素材。
- 仅标注“free”但没有许可证文本的文件。
- 带有第三方商标、产品专有造型或可识别 UI 的临摹。
- 原始个人通信、支付信息、身份证明或未脱敏合同。
