## 证据文案边界

组合控制器只为当前场景定义以下小型 `evidence_copy_role`：

- `observation_cue`：画面中已经可观察的对象或差异。
- `action_affordance`：玩家当前可以执行的操作。
- `neutral_placeholder`：尚未取得证据的锁定状态。
- `post_event_conclusion`：事件完成或卡片解锁后允许显示的结论。
- `system_status`：准备、暂停、速度等应用状态。
- `error`：阻塞性模拟或视图错误。

场景测试检查节点、快照、角色 key、可见性和控件状态，不绑定完整中文句子。锁定卡统一使用控制器常量定义的中性占位；身份阶段未选中个体时，所选内容和命名输入保持隐藏。

## 准备门边界

准备门属于 `CombinedObservationController` 的应用层状态：

1. 创建并冻结配置后的 `ColonySimulation` 仍发布 Tick 0 快照。
2. `SimulationClock` 保持 Tick 0、1×和暂停。
3. `CombinedHabitatView` 的插值系数保持 0，全部视觉节点暂停。
4. 开始按钮只解除应用时钟与视觉暂停。
5. 重新开始先重建干净会话，再回到同一准备门。

它不调用模拟命令、不消费命令队列，也不改变 `ScenarioProgressState`。
