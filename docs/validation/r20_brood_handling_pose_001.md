# R20-E 幼体搬运姿态验证记录 001

日期：2026-07-31
分支：`codex/art/r20-brood-handling-poses`

## 范围与结论

本轮只把已有幼体预订、携带所有权与迁移任务阶段投影为有限程序化姿态：

- 幼体被预订且工蚁处于拾取阶段时，按权威任务进度抬起；
- 幼体实际归属于携带工蚁时，显示携带姿态并继续跟随该工蚁；
- 携带工蚁进入放下阶段时，按权威任务进度回到静止姿态；
- 同一幼体在拾取、携带和放下之间保持同一个稳定 `AntView`；
- 待机／观察工蚁的触角按显示相位轻微探查，移动与减少动效时不叠加该动作。

没有新增模拟状态、所有权、命令、存档字段、Tween、外部素材或通用动画
框架。显示层不会在模拟尚未建立携带所有权时提前把幼体附着到工蚁。

技术结论：通过。R20 整体要求的外部行为识别数据仍未提供，因此本记录不把
R20 整体标记为通过。

## 自动覆盖

- 拾取姿态读取实际预订关系和迁移任务进度；
- 携带姿态只在快照存在实际携带所有权时出现；
- 放下姿态读取实际携带者的放下进度；
- 三段姿态复用同一个幼体视觉节点；
- 显示姿态不改变稳定实体 ID 或生命周期；
- 越界显示进度被限制在 `0.0～1.0`；
- 减少动效保留幼体姿态语义；
- 待机触角使用确定性显示相位，移动与减少动效时冻结；
- 旧生命周期、所有权、存档和最大规模回归继续执行。
