## 覆盖的行为边界

- `BehaviorPose` 只保存在 `AntView`，不进入快照、模拟或存档。
- 相邻 Tick 端点决定水平朝向；固定 Tick 与插值系数决定步态相位。
- 携带糖液、喂食幼体等权威任务映射到已有稳定节点。
- 修改插值不会推进控制器 Tick，也不会修改源快照签名。
- 减少动效冻结步态相位，但保留静态朝向和携带姿态。
- 重复应用快照继续复用稳定 `entity_id -> AntView` 映射。
