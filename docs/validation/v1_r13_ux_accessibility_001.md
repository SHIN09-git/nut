## 范围

本轮没有增加模拟玩法、设施、资源、章节或物种，只收口既有六章的输入与反馈：

- 标题页设置增加独立快捷键页。
- 默认 `F1`／`J`／`L` 分别打开帮助、观察手册和模块布局；三者可重映射。
- 新绑定只接受不会与固定布局编辑、焦点导航和开发 F3 冲突的字母键／功能键；重复绑定原子拒绝。
- `SettingsStore` 格式从 v1 升级到 v2。旧文件只补默认绑定，不改变显示、语言、动效或音量。
- 帮助面板读取当前实际绑定；打开时暂停固定 Tick 与插值，关闭时恢复打开前的暂停状态和焦点。
- 布局合法／非法预览同时使用颜色、勾／叉和文字；闸门开关增加不同线条符号。
- 无效放置、未选择设施、命令待处理和无库存／无合法选项显示带 `!` 的恢复说明。View 只发出有限原因枚举，不修改模拟。

游戏档案仍使用 `r12.authority.v10`。快捷键和辅助设置不进入 SaveEnvelope、模拟 checksum 或快照。
