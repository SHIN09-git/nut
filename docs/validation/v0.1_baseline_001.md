## Windows 导出

新增 `export_presets.cfg`，目标为 Windows Desktop x86_64 release：

```powershell
New-Item -ItemType Directory -Force -Path '.\builds\windows'
& '.\Godot_v4.7.1-stable_win64_console.exe' `
  --headless `
  --path . `
  --export-release 'Windows Desktop' `
  'builds/windows/ColonyUnderGlass_v0.1.exe'
```
