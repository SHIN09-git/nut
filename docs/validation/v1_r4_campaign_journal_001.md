## 结论

R4 已在既有五阶段连续 Demo 上建立两个显式演示短章。首工羽化、湿度搬运和糖水分享成为权威证据；玩家在观察手册中比较证据并提交推论。错误推论只增加最高三级提示，不倒退进度或惩罚档案；正确推论完成章节并解锁固定设施工具包。最终结算同时要求旧五阶段流程和两章推论完成。

这是一套用于验证章节／手册边界的序章骨架，不是正式六章内容。当前设施只解锁稳定类型 ID 并显示在手册中；没有设施摆放、接口或环境效果。

## 权威流程

```text
首工观察卡解锁
→ CampaignDirector 收集首工证据
→ 玩家从观察手册提交推论 ID
→ 下一合法 Tick 应用
→ 错误：递进提示，继续等待推论
→ 正确：确认推论，完成第一章，解锁微型喂食口
→ 湿度观察卡 + 糖水观察卡解锁
→ 收集两项环境证据
→ 玩家提交第二章推论
→ 下一合法 Tick 完成序章，解锁小型觅食盒并开放结算
```

初始工具包固定包含试管巢与遮光套。推论命令是当前唯一携带稳定 `StringName argument_id` 的待处理命令；其他高层命令仍必须为空参数。UI 文案、按钮索引和翻译字符串不进入模拟。
