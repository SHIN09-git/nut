## 范围

本轮不增加玩法、设施、物种或模拟参数，只补充完整档案试玩需要的有效墙钟证据：

- “开始观察”后累计不受 `1×／4×／16×` 影响的聚焦时长；
- 保存总时长、逐章时长和首次结局时长；
- 暂停、帮助与手册阅读计入，标题、准备门和失焦排除；
- 恢复焦点的第一个帧样本排除，避免把系统挂起间隔算入；
- 档案页区分有效观察时间与受倍速影响的模拟历程；
- SaveEnvelope 外层升级到 v2，权威模拟 schema 保持 `r12.authority.v10`；
- 格式 v1 档案从零起记录并显示历史缺口，不伪造过去时长。

## 实现边界

`ProfilePlaytimeState` 由 `GameShellController` 拥有，不进入 `ColonyState`、`GameSnapshot` 或 View。两个可恢复游戏控制器只提供 `{active, chapter, completed}` 的只读上下文，并在保存边界接收已经复制的计时字典。

持久时长使用整数微秒；章节数组固定映射当前八个 `CampaignState.Chapter` 枚举槽位。总时长、各章时长、首次完成时长和历史缺口都由外层 checksum 覆盖。旧格式必须先按原始字段通过 checksum 与冻结配置哈希校验，才会迁移和重新封装。
