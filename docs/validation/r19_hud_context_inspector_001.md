# R19-C 新 HUD、情境操作栏与检查器验证记录

## 结果

R19-C 已把正式 Act 1 的长目标清单和常驻双排工具整理为简短观察轨迹、
情境操作栏和选择后出现的对象检查器。模拟、存档、章节条件、设施规则和
固定 Tick 语义均未改变。

分支：`codex/ux/r19-hud-inspector`

基线提交：`801b1d0`

## 实现

- 顶栏缩短但继续提供章节、运行状态、帮助、暂停和三档速度。
- 普通侧栏只显示一个当前观察目标、最近三条记录和一句下一步方向；完整
  章节时间线继续保留在观察手册。
- 主情境操作栏和布局操作栏禁用水平滚动；布局专用动作只在进入布局编辑后
  出现。
- 工蚁检查器显示稳定实体 ID、可见行为、所在区域和携带物。
- 设施检查器显示稳定设施 ID、区域、非精确环境线索、可见接口数和布局
  状态。
- 检查器与所有普通 UI 只读取复制快照；没有新增模型引用或反写路径。
- 补齐中文暂停按钮和原型节奏提示，英文继续由同一翻译表提供。
