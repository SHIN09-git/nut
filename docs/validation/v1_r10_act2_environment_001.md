## 2. 权威更新顺序

```text

→ 按 sequence 应用高层命令
→ EnvironmentSystem

→ 深复制 GameSnapshot
```

设施放置、旋转、拆除、闸门、糖、蛋白和托盘清理都先进入命令队列，
只在下一连续固定 Tick 重新校验并应用。UI 不传递权威环境量或食物量。

## 3. 章节与设施规则

- 第 3 章证据只读取章节进入后的结构化事件和冻结最小工蚁数。
- 专用糖液台／蛋白盘优先成为对应食物来源的稳定落点。
- 第 4 章的补水证据要求：可用的玩家备用试管、已叠放补水模块，
  且该备用试管湿度处于冻结育幼舒适范围。
- 污染规避证据来自迁移放下事件的来源／目标污染差，不读取屏幕颜色。
- 环境稳定窗口要求非工蚁位于舒适、低污染区域，且工蚁工作任务空闲。
- 连接与闸门仍由稳定设施／连接 ID 派生；关闭闸门在提交 Tick 不改变可达图。
- View 只读取快照。布局叠加设施使用小型半透明图标，基础设施标签最后绘制，
  不让补水模块遮住备用试管名称。
