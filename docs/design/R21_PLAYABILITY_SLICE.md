# R21 第 1～2 章可玩性垂直切片

## 范围

R21 只增强现有第一幕的第 1～2 章，不重写权威模拟，也不扩写第 3～6 章。固定
0.1 秒 Tick、稳定实体 ID、快照边界、现有章节证据和推论仍是事实来源。

R20 的 5 人行为辨认 Gate 已由用户明确豁免，因此允许进入 R21；该豁免不等于
R20 真人测试通过，也不豁免 R21 自身的外测 Gate。

## 玩家循环

第 1 章与第 2 章都使用同一条实验循环：

1. 手册提出当前观察问题。
2. 玩家在干预前记录一项预测。
3. 玩家通过工具栏执行环境干预。
4. 手册并列显示干预前基线和当前结果。
5. 事件时间线记录关键行为。
6. 证据充分后，玩家提交既有章节推论。

预测、首工名字和实验基线是本次游玩的观察注释，不是权威模拟状态，不写入
存档。加载一个已经越过干预点的旧存档时，界面不得倒退阻塞已有进度。

## 第 1 章

- 当前问题：遮光后，蚁后对幼体的行为会怎样变化？
- 玩家先预测“护理增加”“没有明显变化”或“远离幼体”。
- 遮光套仍通过既有高层命令在下一 Tick 安装。
- 前后对照至少显示遮光状态和已完成护理次数。

## 第 2 章

- 当前问题：糖液出现后，首工会怎样取得并分享食物？
- 玩家先预测“自主往返分享”“停在原地”或“需要逐步指挥”。
- 首工保留稳定实体 ID；玩家可在实验记录中命名并查看最近行为历史。
- 糖液使用一个高层落点选择，而不是由 UI 传入任意区域 ID：
  - `feeding_port`：远端喂食口，路线较长，不打断蚁后护理；
  - `near_nest`：近巢通道，路线较短，但放置动作会打断蚁后当前护理循环。
- 近巢扰动只把既有护理状态机重置到休息起点，不添加伤害、货币或新需求系统。
- 糖液命令仍在下一 Tick 开始时应用；选择 ID 由启动时冻结的场景配置解析。

## 关键事件减速

当第一只工蚁羽化、首次糖液采集、首次分享或章节完成发生时，如果当前速度高于
1×，控制器在接收该快照后切回 1×。这只改变之后现实时间内处理 Tick 的速率，
不改写已经发生的模拟结果，也不改变固定 Tick 语义。暂停状态保持暂停。

## 展示边界

- 普通界面显示问题、预测、前后对照、相对秒数时间线和首工历史。
- 精确 Tick、内部枚举和实体 ID 仍只在调试层显示。
- 近巢扰动反馈由观察事件和当前 Tick 驱动，暂停时不会自行推进。
- View 只读取 `GameSnapshot`，不接触或反写模型。

## 验证边界

自动测试覆盖：

- 落点选择在提交时不改变状态，并在下一 Tick 使用冻结配置；
- 近巢选择重置护理循环，远端选择不重置；
- 相同初始状态和命令序列保持确定性；
- 预测门控、真实糖液选择按钮、前后对照和实验时间线；
- 首工命名与历史；
- 关键事件减速不改变快照结果；
- 存档往返与旧测试保持通过。

R21 的 5 人无讲解外测仍是进入 R22 前的独立 Gate。技术候选可以完成并推送，
但没有有效外测或新的明确豁免时不得进入 R22。
