# v1 失败与恢复规则

状态：R1 生产规格

首发目标是“可恢复的环境问题”，不是突然死亡、不可逆坏档或隐性惩罚。失败用于推动观察和修正，不用于删除数小时进度。

## 通用原则

1. 模拟命令在下一合法 Tick 原子应用；验证失败时不产生部分修改。
2. 任何恢复操作都不能直接指定某只蚂蚁执行任务。
3. 存档前后必须保持相同问题、待处理命令和恢复机会。
4. 普通 UI 先显示可观察线索，再提供分级帮助；诊断值只在开发层。
5. 章节关键路径始终保留至少一个可达、安全、可修复的状态。

## 失败矩阵

| 类别 | 触发 | 玩家可见线索 | 系统后果 | 恢复方式 | 永久损失 |
| --- | --- | --- | --- | --- | --- |
| 无效设施放置 | 占地、接口、解锁或供应不满足 | 预览轮廓无效、说明具体规则 | 命令原子拒绝，不消耗供应 | 选择合法槽位／方向 | 无 |
| 危险拆除 | 设施仍被实体、任务或资源引用 | 被占用对象高亮、原因摘要 | 命令拒绝 | 等任务结束、迁移资源或恢复连接 | 无 |
| 糖类不足 | 糖类储备低于舒适阈值 | 工蚁活动减缓、糖液台空 | 活动节奏降低，不立即死亡 | 补充糖液并等待自主采集／分享 | 无 |
| 蛋白不足 | 幼体蛋白供给不足 | 幼体成长放缓、蛋白皿空 | 生命周期成长变慢 | 补充蛋白并等待搬运／喂食 | 无 |
| 湿度不适 | 可用育幼区偏离偏好 | 凝水／基质线索、幼体迁移 | 工蚁重新分区，成长可能减慢 | 补水、开放备用区、调整连接 | 无 |
| 污染偏高 | 废物负担累积 | 污点、废物堆、工蚁回避 | 区域适宜度下降 | 提供垃圾托盘、等待集中后安全清理 | 无 |
| 路径中断 | 闸门关闭或连接变化 | 通道状态、工蚁等待／折返 | 新任务停止分配；携带任务保留所有权 | 重新开放有效路径 | 无 |
| 迁巢停滞 | 新巢不舒适或连接不完整 | 侦察后返回、搬运停止 | 迁巢进度暂停 | 修正连接、湿度或污染 | 无 |
| 章节目标不清 | 玩家长时间无有效操作 | 先环境线索，再手册提示 | 不自动代做 | 三级提示逐步揭示观察位置与操作边界 | 无 |
| 存档损坏 | 校验、版本或不变量失败 | 明确恢复对话框 | 活跃会话不被替换 | 从最后完整备份恢复，保留坏档副本供诊断 | 最多丢失最后一次成功保存后的进度 |

## 三级提示

1. **线索**：指出画面中发生变化的区域或行为，不给答案。
2. **方向**：提醒比较两个环境／设施状态，仍不说明结论。
3. **操作帮助**：说明可使用哪个工具和合法区域，但不指定工蚁。

提示使用会记入本地档案统计，只用于产品验证，不影响模拟结果或结局。

## 保护状态

- 开局和每章进入时至少存在一个合法安全区域。
- 关键食物用尽后，玩家工具仍能获得完成当前章所需的最低补充次数，不建立货币。
- 关闭闸门若会使携带实体无合法放下区域，命令必须拒绝。
- 蚁后和全部幼体不会因单次错误操作立即死亡；首发不实现不可逆群落灭绝结局。
- 若内部不变量、非连续 Tick 或存档加载失败，主流程进入可见暂停错误状态，不继续分叉。

## 章节恢复检查点

- 自动保存仅在固定 Tick 边界和权威状态通过不变量后请求。
- 章开始与章完成各保留一个轮换备份。
- “重新开始当前章节”从章开始检查点恢复，不重置整个档案。
- “新档案”与“删除档案”属于应用外壳，删除必须二次确认并另行实现。

## 禁止做法

- 静默修正非法所有权或负资源。
- 失败后直接传送蚂蚁、幼体或资源到目标。
- 用无限免费资源掩盖守恒错误。
- 因 UI 误点立即删除设施或档案。
- 通过降低速度、冻结画面或无信息等待制造“恢复过程”。
