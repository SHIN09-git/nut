# R18-1 UI 组件与主题等价性审查

## 结论

R18-1 只调整 UI 的代码所有权和主题资源位置。标题页、第一章观察页、
准备门、手册、帮助、完成页和暂停菜单的节点路径、主要尺寸、配色、文案、
按键路径和模拟命令边界保持不变。

本轮没有修改模拟 schema、章节条件、设施规则、配置 Resource、存档格式或
权威状态更新顺序。

## 结构变化

- 标题页与观察页的按钮主题分别移入
  `themes/game_shell_theme.tres` 和
  `themes/act1_observation_theme.tres`。
- 观察卡片共用
  `themes/styles/observation_card.tres`，不再在大场景中复制同一份样式。
- 标题栏、观察侧栏、工具栏、准备门、手册、帮助、完成页和暂停菜单拥有
  独立的 UI 组件脚本。
- `Act1TestTubeController` 只连接这些组件发出的高层 UI 信号，不再逐个保存
  所有子按钮和标签的引用。
- 控制器的 `@onready` 引用从 65 个降为 11 个。
- 现有 `%NodeName` 保持不变，场景测试和键盘焦点路径继续使用原节点。

## 交互等价性

真实窗口中已执行：

- 新游戏 → 准备门 → 开始观察。
- `F1` 打开帮助，`Esc` 关闭帮助。
- `Esc` 打开暂停菜单。
- `Tab` 在暂停菜单中移动焦点，`Enter` 执行“保存并返回标题”。
- 从标题页进入设置，切换中文／英文、100%／150% 和
  1280×720／1920×1080。
- 从标题页继续存档，并从暂停状态恢复观察。

上述路径均可用。自动场景测试继续通过真实按钮验证高层信号最终进入原有
控制器和模拟命令边界。

## 保留问题

- R18-1 不改变 R18 基线中记录的世界画面占比、布局模式成本或行为辨识度；
  这些属于 R19 及后续体验工作。
- 按用户指示，本轮不等待“7 名有效首次接触测试者”数据；这项外部证据仍
  标记为未执行，不能被解释为外测通过。
- 1366×768、全屏和 1920×1080 的 150% 组合未在本轮重复检查。
