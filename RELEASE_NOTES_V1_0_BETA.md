# Colony Under Glass v1.0 Beta Candidate

Candidate date: 2026-07-29

This is the first release-candidate line for the complete six-chapter
single-player observation game. It is not a `main` merge, GitHub Release, store
release, or `v1.0.0` tag.

## Main experience

- Follow one colony from founding care and the first worker through nutrition,
  foraging, environmental management, modular expansion, core migration, and
  a final glass-observation report.
- Shape behavior indirectly through cover, hydration, food, waste handling,
  connected facilities, and gates.
- Build with twelve readable facility and connector types on a deterministic
  logical layout.
- Observe autonomous brood care, foraging, feeding, cleaning, scouting, and
  brood-first/queen-last migration.
- Continue observing after the six-chapter conclusion or save and return to
  the title.

## Application features

- One local profile with explicit save, backup recovery, continue, and
  confirmed deletion.
- Versioned migration from every repository save fixture from
  `r2.authority.v1` through the current `r12.authority.v10` format.
- 1280×720 and 1920×1080 windowed modes, fullscreen, 100%/125%/150% UI scale,
  and reduced motion.
- Keyboard navigation, remappable Help/Journal/Layout shortcuts, explicit
  focus, non-color-only placement feedback, and an in-game controls page.
- Simplified Chinese and English.
- Separate master, ambient, and effects volume controls.
- Project-original production visuals and deterministic synthesized audio.
- In-game Credits & Privacy page and accompanying release documents.

## Compatibility and distribution

- Windows x86_64.
- Built with the official Godot 4.7.1 stable export template using the
  Compatibility renderer.
- Portable unsigned distribution; no installer, platform SDK, DRM, account,
  telemetry, or network service.
- Source tests, tools, debug scenes, internal reference material, and editor
  data are excluded from the release package.

## Important beta notes

- Species values and pacing remain clearly marked
  `prototype_pacing_fixture`; they are not scientific husbandry guidance.
- The complete profile is designed for an approximately 3–4 hour first run,
  but the required final external full-profile sample has not been supplied.
  Completion rate, median duration, comprehension, and first-contact usability
  therefore remain `INCOMPLETE`, not passed.
- The build is unsigned, so Windows may show a reputation warning.
- Temperature, multiple species, combat, free excavation, multiplayer, cloud
  saves, Steam integration, achievements, and offline progression are not part
  of this release.

## Verification

Technical regression, long-run, maximum-scale, migration, clean-environment,
window, and package-hash evidence is recorded in
